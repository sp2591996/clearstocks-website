# ClearStocks

A free Nifty 200 stock screener and ML-ranking site, with downloadable
per-stock "Company Deck" PDF reports.

This repository holds the static website (HTML/CSS/JS), the underlying
data files, and the 200 company deck PDFs. Automation for keeping prices
fresh and decks up to date will be added as GitHub Actions workflows.

Live site: enabled via GitHub Pages once this repo is pushed (Settings →
Pages → Source: `main` branch, `/ (root)`).
